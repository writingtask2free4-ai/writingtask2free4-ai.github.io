Har bir dasturchi yoki yozuvchi uchun **shaxsiy veb-sayt** — bu shunchaki chiroyli ko'rinish emas, balki o'z ovozingizni topish uchun eng arzon va eng mustaqil yo'l.

Bu saytni GitHub Pages'da, hech qanday server yoki to'lov qilmasdan joylashtirdim. Quyida asosiy sabablarni sanab o'taman.

## Nega statik sayt?

Statik sayt — ma'lumotlar bazasi yo'q, backend yo'q, faqat HTML, CSS va JavaScript fayllari. Bu degani:

- Sayt juda tez yuklanadi
- Xavfsizlik muammolari deyarli yo'q
- GitHub Pages orqali butunlay **bepul** joylashtirsa bo'ladi
- Har qanday o'zgarishni oddiy fayl tahrirlash orqali qilsa bo'ladi

## Qanday ishlaydi

Har bir maqola alohida `.md` (Markdown) fayl sifatida yoziladi. Sayt ochilganda JavaScript ushbu faylni o'qiydi va uni chiroyli HTML sahifaga aylantiradi. Shu tufayli yangi maqola qo'shish uchun kod yozish shart emas — shunchaki yangi matn fayl yaratish kifoya.

> Eng yaxshi vosita — bu sizga halaqit bermaydigan vosita.

Keyingi maqolalarda loyihalarim va o'rganayotgan narsalarim haqida yozib boraman.
